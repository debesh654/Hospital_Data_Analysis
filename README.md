Hospital Management and Bed Occupancy Analysis

Project Overview

This project analyzes hospital data using Python and provides an interactive dashboard using Streamlit.

Objectives

- Clean and process hospital data.
- Analyze hospital bed occupancy.
- Calculate available beds.
- Analyze ICU occupancy.
- Compare patient admissions and discharges.
- Forecast bed occupancy using a 7-record rolling average.
- Perform hospital capacity scenario analysis.

Technologies Used

- Python
- Pandas
- Matplotlib
- Streamlit
- Excel

Project Features

1. Hospital Dashboard
2. Bed Occupancy Analysis
3. ICU Occupancy Analysis
4. Patient Admissions and Discharges
5. Bed Occupancy Forecasting
6. Scenario Analysis
7. Cleaned Dataset Download

Installation

Install the required libraries:

pip install -r requirements.txt

Run the Application

streamlit run app.py

Project Files

- "app.py" – Streamlit frontend
- "analysis.py" – Python data analysis
- "Hospital_Data.xlsx" – Input dataset
- "requirements.txt" – Required Python libraries
- "Cleaned_Hospital_Data.csv" – Cleaned dataset
